<h2>📖 О проекте</h2>

<p>
<b>Chatlog Magician</b> — это полностью переработанная и улучшенная версия оригинального Chatlog Magician для LS-RP.
</p>

<p>
Инструмент позволяет быстро превращать чатлоги SA-MP / GTA World в красивые игровые скриншоты, упрощая создание RP-ситуаций, биографий, топиков и другого контента.
</p>

<blockquote>
⚡ Полная совместимость с SA-MP<br>
⚡ Поддержка GTA World<br>
⚡ Современный интерфейс<br>
⚡ Высокая производительность
</blockquote>

<h2>🚀 Использование</h2>

<ol>
<li>Вставьте ваш чатлог в текстовое поле</li>
<li>Настройте размер шрифта и длину строк</li>
<li>Используйте фильтр персонажей для выделения нужных диалогов</li>
<li>Включите или отключите фон</li>
<li>Нажмите <b>Download</b> для сохранения изображения</li>
</ol>

---

<h2>📱 Специальное форматирование</h2>

<h3>☎️ Телефонные разговоры</h3>

<p>Добавьте <code>!</code> в начало строки:</p>

<pre><code>!John says (cellphone): Привет!</code></pre>

<p>Строка станет желтой.</p>

---

<h3>🔞 Цензура</h3>

<p>Используйте символ <code>÷</code>:</p>

<pre><code>Я живу на ÷Grove Street÷</code></pre>
